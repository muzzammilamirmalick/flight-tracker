# My Sky (web)

React app that shows the planes over my home in Hamilton, using the flight tracker API.

## Run it

```
npm install
npm run dev
```

Then open http://localhost:5173. The API needs to be running too (see the main README).

## Settings

Copy `.env.example` to `.env.local` to change the API address or the home point.

Map tiles are from [OpenFreeMap](https://openfreemap.org), map data from OpenStreetMap.
